# Three Craft

A browser-based Voxel / Minecraft-inspired 3D game built with Three.js, React, and TypeScript.

## Tech Stack

* **Framework:** React, TypeScript, Vite
* **3D Graphics:** Three.js
* **Styling:** Tailwind CSS / CSS
* **Live Demo:** [three-craft-three.vercel.app](https://three-craft-three.vercel.app)

---

## Project Structure

```text
three-craft/
├── Items/             # Item definitions and management
├── Mechanics/         # Gameplay mechanics (physics, interactions, control loops)
├── Render/            # Three.js rendering logic and scene setups
├── Technical/         # Core helper functions and utility modules
├── World/             # World generation, chunks, and block systems
├── components/        # React UI components
├── engine/            # Main game engine loop and state management
├── App.tsx            # Root React component
└── index.tsx          # Application entry point
